# Parser sibling audit (review rounds 1-19)

Every finding from the nineteen review rounds of the parser branch, grouped by class. Each class
was checked against every tool the parser models, and every verb in it where the class can
apply. A cell is **fixed** (with the round it was fixed in), **n/a** with the reason, or, for
round 9, the fix in this round. Each fixed cell has a row in `tests/test_parser_audit.py`
(the C-number and tool are its test id), besides the focused tests in
`tests/test_parser_flag_reading.py`.

Tools: kubectl, helm, flux, argocd, gh, git, aws, az, gcloud, gsutil.
